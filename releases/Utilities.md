# Utilities

Space-wide views that belong to no other library: a tag cloud, a health
table that counts what needs attention in a space, with a detail page per
check. Change proposals are not part of it: the Proposals library of the
[SilverBullet MCP server](https://github.com/finestream/silverbullet-mcp-server)
lists, reviews and applies them (`${proposals.list()}`).

Nothing is stored: every view is computed from the index and the pages when it
is shown. Pages call `utilities.tagCloud()` and `utilities.health()` only, so a
space that restricts what pages may call needs just these two entries on its
allowlist.

**Upgrading from 0.x:** `utilities.proposals()`, `utilities.review()` and the
virtual page `proposal:<name>` are gone. Replace `${utilities.proposals()}` on
your pages with `${proposals.list()}`, and drop `utilities.proposals` and
`utilities.review` from the allowlist.

## Features

* *Tag cloud* every tag of the space once, alphabetically, as links to its tag
  page.
* *Health table* one row per check with its count and a link to its detail:
  * *MCP scan: findings* and *files that are not pages*: the counts from the
    report page of the [SilverBullet MCP server](https://github.com/finestream/silverbullet-mcp-server)'s
    scan, and whether it blocks rendering;
  * *Conflicts*: `.conflicted` copies and, if `conflictMarkers` is on, pages
    with conflict markers;
  * *Aspiring pages*: links to pages that do not exist;
  * *Invalid frontmatter*: formal pages whose frontmatter fails validation;
  * *Status without a schema*: pages with a `status` that no schema checks;
  * *Capitalised Status*: pages whose frontmatter says `Status` instead of
    `status`;
  * *Decisions proposed* and *due for review*: decision records (`#dr`);
  * *Tasks overdue* and *without due date*: open tasks of the Kanboard
    library's cache;
  * *Pages waiting for review*: pages in a configured folder (for example
    where agents write) that have been `proposed` for too long.
  * *Open proposals*: change proposals of the Proposals library that are open.
* *Detail pages* `health:<check>` lists the pages behind a count, as links.
* *Safe output* text from the space (page and tag names, frontmatter values,
  error messages) is never written into the page as is: a page name becomes a
  link only when it cannot break out of one or start like a URL
  (`javascript:`), everything else is shown in a code span, where SilverBullet
  evaluates no directive and renders no HTML.

## Formal and informal pages

A page is *formal* when one of its tags is defined with `tag.define` and a
`schema` or a `validate` function (the ITAM library defines such tags);
every other page is *informal*, with free frontmatter, and is never counted by
*Invalid frontmatter*. Each such tag is checked as the editor's lint does:
`jsonschema.validateObject` with the schema, then `validate`. A tag defined
with `mustValidate = true` keeps a failing page out of the index altogether,
so this check cannot see such a page.

## Where each check reads its data

* *MCP scan*: the headings `Findings (N)` and `Files that are not pages (N)`
  and the list item `Rendering: …` of the report page (`mcpPage`), read from
  the index. Without that page both rows say *no report*.
* *Conflicts*: page and file names containing `.conflicted`, from the index.
  With `conflictMarkers = true` also the text of every page that is not
  excluded, for a line starting with `<<<<<<<` followed by `=======` and
  `>>>>>>>`. SilverBullet indexes only the name of a page with conflict
  markers, so the text has to be read. That is why it is off by default: with
  it off the health table reads no page text, and a user who may not read
  every page (an agent, say) can still render a page that shows the table.
* *Status without a schema*: pages with a `status` in their frontmatter and
  no tag whose definition (`tag.define`) has a schema with a `status`
  property. The tags are read from the definitions, not listed here: with the
  ITAM library they are `dr` and every kind configured with a `status`. No
  schema checks such a value, so a query on `status` cannot rely on it. In a
  space where no tag defines `status` the field is free and the row is not
  shown.
* *Capitalised Status*: pages with a `Status` key. YAML keys are
  case-sensitive, so this is another field than `status`: no schema checks it
  and a query on `status` misses the page.
* *Decisions*: pages tagged `dr`. *Proposed* means `status: proposed`. *Due
  for review* uses the ITAM library's rule and setting (an active status, and
  `lastReviewed` missing or older than its `reviewDays`); without ITAM the row
  is not shown.
* *Tasks*: tasks with a `kbId` (the Kanboard library's cache) that are not
  done; *overdue* means a due date before today, *without due date*
  `dueRaw == 0`.
* *Pages waiting for review*: pages under `proposedPrefix` with
  `status: proposed` whose frontmatter `date` (or, without one, the last
  change) is more than `proposedDays` days ago. Without `proposedPrefix` the
  row is not shown.
* *Open proposals*: pages tagged `change-proposal` under the Proposals
  library's folder (its `proposals.proposalPrefix`, default `Proposals/`)
  whose `outcome` is `open` or missing. The detail page links each to its
  review page `review:<name>`.

## Configuration

Configuration is optional; without it every view works, and only the check
*Pages waiting for review* is not shown. To change the defaults, add the
following section to your `CONFIG` page in a space-lua block:

```lua
config.set {
  utilities = {
    exclude = { "Library/" },   -- pages left out of every view (default)
    mcpPage = "MCP Server",     -- report page of the MCP server's scan (default)
    proposedPrefix = "Drafts/", -- folder of pages waiting for review (no default)
    proposedDays = 7,           -- days a page may wait in `proposed` (default)
    conflictMarkers = true,     -- read every page for conflict markers (default: false)
  }
}
```

`exclude` applies to the tag cloud (tags that occur only on excluded pages),
to the pages that link to aspiring pages, and to every other check.

## Usage

### Tag cloud

```
${utilities.tagCloud()}
```

Tags starting with `meta` are left out, as are tag names that hold a
character that could break the link (`[ ] | { } $ < >` or a backtick) or
that starts like a URL scheme (`name:`).

The cloud is a block with the CSS class `utilities-tag-cloud`; its look is the
style block below, which a `space-style` block of your own can override. The
links are spaced out, because SilverBullet draws a wiki link with a padding
and the same negative margin, so that links separated only by a space touch.

### Health

```
${utilities.health()}
```

The *Detail* column links to the check's detail page, for example
`[[health:aspiring]]`; the MCP rows link to the report page.

## Code

```space-lua
-----------------------------------------------------------------------
-- Package utilities
--
-- Space-wide views that belong to no other library: the tag cloud and
-- the health table (health.lua). Pages call utilities.tagCloud() and
-- utilities.health() only.
--
-- Everything is computed from the index when a page is shown; nothing
-- is stored. Text that comes from the space (page names, tag names,
-- frontmatter values, error messages) is never written into markdown
-- as is: page names become links only when they cannot break out of
-- one, everything else goes into a code span (utilities.code).
-----------------------------------------------------------------------
utilities = utilities or {}

-----------------------------------------------------------------------
-- utilities.defaults
--
-- Fallback values for the "utilities" section of the CONFIG page.
-- proposedPrefix has no default: the check it drives is shown only
-- once a folder is configured.
-----------------------------------------------------------------------
utilities.defaults = {
	exclude = { "Library/" },  -- pages left out of every view
	mcpPage = "MCP Server",    -- report page of the MCP server's scan
	proposedPrefix = nil,      -- folder of pages waiting for review; nil: no check
	proposedDays = 7,          -- days a page may wait in `proposed`
	conflictMarkers = false    -- read page texts for conflict markers (opt-in)
}

-----------------------------------------------------------------------
-- utilities.config()
--
-- Reads the "utilities" section of the CONFIG page.
--
-- Returns:
--   Table with the configured values, and the defaults for every key
--   the user did not configure.
-----------------------------------------------------------------------
function utilities.config()
	local effective = {}
	for key, value in pairs(utilities.defaults) do effective[key] = value end
	for key, value in pairs(config.get("utilities", {}) or {}) do effective[key] = value end
	return effective
end

-----------------------------------------------------------------------
-- utilities.excluded(name)
--
-- Whether a page (or document) name starts with one of the configured
-- `exclude` prefixes.
-----------------------------------------------------------------------
function utilities.excluded(name)
	for _, prefix in ipairs(utilities.config().exclude or {}) do
		if string.startsWith(name, prefix) then return true end
	end
	return false
end

-----------------------------------------------------------------------
-- utilities.safeName(name)
--
-- Whether a name can be written into a wiki link or a tag link as is:
-- no brackets, pipes, braces, dollars, angle brackets, backticks or
-- line breaks, which could end the link or start a directive or HTML,
-- and no leading URL scheme ("javascript:"), which could turn the link
-- into something other than a page.
-----------------------------------------------------------------------
function utilities.safeName(name)
	if type(name) ~= "string" or name == "" then return false end
	if string.find(name, "^%a[%w+-]*:") then return false end
	return string.find(name, "[%[%]|{}%$<>`\r\n]") == nil
end

-----------------------------------------------------------------------
-- utilities.code(text)
--
-- Any value as an inert markdown code span, fit for a table cell.
--
-- The fence is one backtick longer than the longest run of backticks
-- in the text, line breaks become spaces and pipes are escaped, so
-- the text can neither end the span nor the table cell. Inside a code
-- span SilverBullet evaluates no directive and renders no HTML.
--
-- Returns:
--   The code span, or "" for nil and the empty string.
-----------------------------------------------------------------------
function utilities.code(text)
	if text == nil then return "" end
	local flat = string.gsub(tostring(text), "[\r\n]+", " ")
	if flat == "" then return "" end
	local longest = 0
	for run in string.gmatch(flat, "`+") do
		if #run > longest then longest = #run end
	end
	local fence = string.rep("`", longest + 1)
	local escaped = string.gsub(flat, "|", "\\|")
	return fence .. " " .. escaped .. " " .. fence
end

-----------------------------------------------------------------------
-- utilities.link(name)
--
-- A page name as a wiki link when that is safe, as a code span
-- otherwise.
-----------------------------------------------------------------------
function utilities.link(name)
	if utilities.safeName(name) then return "[[" .. name .. "]]" end
	return utilities.code(name)
end

-----------------------------------------------------------------------
-- utilities.table(columns, rows)
--
-- A markdown table. Cells must already be markdown (utilities.code,
-- utilities.link or numbers).
--
-- Returns:
--   The table, or "*None.*" when there are no rows.
-----------------------------------------------------------------------
function utilities.table(columns, rows)
	if #rows == 0 then return "*None.*" end
	local lines = {
		"| " .. table.concat(columns, " | ") .. " |",
		"|" .. string.rep(" --- |", #columns)
	}
	for _, row in ipairs(rows) do
		local cells = {}
		for i = 1, #columns do
			local value = row[i]
			if value == nil then value = "" end
			table.insert(cells, tostring(value))
		end
		table.insert(lines, "| " .. table.concat(cells, " | ") .. " |")
	end
	return table.concat(lines, "\n")
end

-----------------------------------------------------------------------
-- utilities.today()
--
-- Today's date as "YYYY-MM-DD", for comparing with frontmatter dates.
-----------------------------------------------------------------------
function utilities.today()
	return os.date("%Y-%m-%d")
end

-----------------------------------------------------------------------
-- utilities.daysAgo(days)
--
-- The date `days` days before today as "YYYY-MM-DD".
-----------------------------------------------------------------------
function utilities.daysAgo(days)
	return os.date("%Y-%m-%d", os.time() - days * 86400)
end

-----------------------------------------------------------------------
-- utilities.day(value)
--
-- The "YYYY-MM-DD" part of a date or timestamp value, or nil.
-----------------------------------------------------------------------
function utilities.day(value)
	if value == nil then return nil end
	return string.match(tostring(value), "^(%d%d%d%d%-%d%d%-%d%d)")
end

-----------------------------------------------------------------------
-- utilities.tagCloud()
--
-- Every tag of the space once, alphabetically, as tag links
-- ([[tag:x|#x]]), for use on a page: ${utilities.tagCloud()}.
--
-- Left out: tags starting with "meta", tags that occur only on pages
-- matching the `exclude` prefixes, and tags whose name could break the
-- link (utilities.safeName).
--
-- The links are markdown in a block widget with the CSS class
-- utilities-tag-cloud. SilverBullet draws a wiki link with a padding
-- and the same negative margin, so links separated by a space touch;
-- the library's space-style block spaces them out through that class,
-- and a space-style block of the space can override it.
--
-- Returns:
--   A block widget with the links ("" when there is no tag).
-----------------------------------------------------------------------
function utilities.tagCloud()
	local seen, out = {}, {}
	local tags = query[[from t = index.tag "tag" order by t.name]]
	for _, t in ipairs(tags) do
		if not seen[t.name]
			and not string.startsWith(t.name, "meta")
			and not utilities.excluded(t.page)
			and utilities.safeName(t.name) then
			seen[t.name] = true
			table.insert(out, "[[tag:" .. t.name .. "|#" .. t.name .. "]]")
		end
	end
	if #out == 0 then return "" end
	return widget.new {
		markdown = table.concat(out, " "),
		display = "block",
		cssClasses = { "utilities-tag-cloud" }
	}
end

-----------------------------------------------------------------------
-- Package utilities (health)
--
-- The health table of the space: ${utilities.health()} shows one row
-- per check with a count and a link to the check's detail, the
-- virtual page health:<key>.
--
-- A check either lists rows (pages, tasks, ...), which are its detail
-- and whose number is its count, or reads a count from the report page
-- of the MCP server's scan. Both the table and the detail pages call
-- the same functions, so they cannot disagree.
-----------------------------------------------------------------------

-----------------------------------------------------------------------
-- utilities.mcpReport()
--
-- Reads the report page of the MCP server's scan from the index: the
-- counts in the headings "Findings (N)" and "Files that are not pages
-- (N)", and whether the list item "Rendering: ..." says it is blocked.
--
-- Returns:
--   Table { findings, files, blocked }, or nil when the page has no
--   such headings (not installed, not indexed yet).
-----------------------------------------------------------------------
function utilities.mcpReport()
	local name = utilities.config().mcpPage
	local report = { blocked = false }
	local headers = query[[from h = index.tag "header" where h.page == name]]
	for _, h in ipairs(headers) do
		local findings = string.match(h.name, "^Findings %((%d+)%)")
		if findings then report.findings = tonumber(findings) end
		local files = string.match(h.name, "^Files that are not pages %((%d+)%)")
		if files then report.files = tonumber(files) end
	end
	if report.findings == nil and report.files == nil then return nil end
	local items = query[[from i = index.tag "item" where i.page == name]]
	for _, i in ipairs(items) do
		if i.text and string.startsWith(i.text, "Rendering:") and string.find(i.text, "blocked", 1, true) then
			report.blocked = true
		end
	end
	return report
end

-----------------------------------------------------------------------
-- utilities.hasConflictMarkers(text)
--
-- Whether a page text holds a conflict: a line starting with
-- "<<<<<<<", a later "=======" and a later ">>>>>>>". This is what
-- SilverBullet writes when two edits cannot be merged.
-----------------------------------------------------------------------
function utilities.hasConflictMarkers(text)
	local padded = "\n" .. text
	local start = string.find(padded, "\n<<<<<<<", 1, true)
	if not start then return false end
	local separator = string.find(padded, "\n=======", start, true)
	if not separator then return false end
	return string.find(padded, "\n>>>>>>>", separator, true) ~= nil
end

-----------------------------------------------------------------------
-- utilities.conflicts()
--
-- Pages and files in conflict: copies whose name holds ".conflicted"
-- (written by older versions of SilverBullet, and by 2.12 for files it
-- cannot merge), and pages holding conflict markers. A page with
-- markers keeps only its name in the index, so finding it means reading
-- every page that is not excluded. That is done only when the
-- `conflictMarkers` setting is on: a render of the health table then
-- loads no page text by default, so an agent that may not read a folder
-- can still render a page that shows it.
--
-- Returns:
--   Rows { page, kind }.
-----------------------------------------------------------------------
function utilities.conflicts()
	local rows = {}
	local markers = utilities.config().conflictMarkers == true
	for _, p in ipairs(query[[from p = index.pages() order by p.name]]) do
		if not utilities.excluded(p.name) then
			if string.find(p.name, ".conflicted", 1, true) then
				table.insert(rows, { utilities.link(p.name), "copy" })
			elseif markers and utilities.hasConflictMarkers(space.readPage(p.name)) then
				table.insert(rows, { utilities.link(p.name), "conflict markers" })
			end
		end
	end
	for _, d in ipairs(query[[from d = index.documents() order by d.name]]) do
		if not utilities.excluded(d.name) and string.find(d.name, ".conflicted", 1, true) then
			table.insert(rows, { utilities.code(d.name), "copy" })
		end
	end
	return rows
end

-----------------------------------------------------------------------
-- utilities.aspiring()
--
-- Links to pages that do not exist, from pages that are not excluded.
--
-- Returns:
--   Rows { missing page, linked from }, one per missing page.
-----------------------------------------------------------------------
function utilities.aspiring()
	local from, names = {}, {}
	for _, a in ipairs(query[[from a = index.aspiringPages() order by a.name]]) do
		if not utilities.excluded(a.page) then
			if not from[a.name] then
				from[a.name] = {}
				table.insert(names, a.name)
			end
			from[a.name][a.page] = true
		end
	end
	local rows = {}
	for _, name in ipairs(names) do
		local pages = {}
		for page in pairs(from[name]) do table.insert(pages, page) end
		table.sort(pages)
		local links = {}
		for _, page in ipairs(pages) do table.insert(links, utilities.link(page)) end
		table.insert(rows, { utilities.link(name), table.concat(links, ", ") })
	end
	return rows
end

-----------------------------------------------------------------------
-- utilities.invalidFrontmatter()
--
-- Formal pages whose frontmatter fails validation. A page is formal
-- when one of its tags is defined (tag.define) with a `schema` or a
-- `validate` function; every other page is informal and never
-- counted. Each such tag is checked as SilverBullet's editor does:
-- jsonschema.validateObject with the schema, then `validate`.
--
-- A tag defined with mustValidate = true keeps a failing page out of
-- the index altogether, so such pages cannot be seen here.
--
-- Returns:
--   Rows { page, tag, error }.
-----------------------------------------------------------------------
function utilities.invalidFrontmatter()
	local definitions = config.get("tags", {}) or {}
	local rows = {}
	for _, p in ipairs(query[[from p = index.pages() order by p.name]]) do
		if not utilities.excluded(p.name) then
			for _, t in ipairs(p.tags or {}) do
				local definition = definitions[t]
				if definition and (definition.schema or definition.validate) then
					local err
					if definition.schema then
						err = jsonschema.validateObject(definition.schema, p)
					end
					if not err and definition.validate then
						local ok, result = pcall(definition.validate, p)
						if not ok then
							err = "validate failed: " .. tostring(result)
						else
							err = result
						end
					end
					if err then
						table.insert(rows, { utilities.link(p.name), utilities.code("#" .. t), utilities.code(err) })
					end
				end
			end
		end
	end
	return rows
end

-----------------------------------------------------------------------
-- utilities.statusTags()
--
-- The tags whose definition (tag.define) has a schema with a `status`
-- property: the tags of this space that say what `status` means. With
-- the ITAM library these are its kinds that have a `status` and `dr`;
-- nothing here names a tag.
--
-- Returns:
--   Set { [tag] = true }, and the number of tags in it.
-----------------------------------------------------------------------
function utilities.statusTags()
	local tags, count = {}, 0
	for name, definition in pairs(config.get("tags", {}) or {}) do
		local properties = definition.schema and definition.schema.properties
		if properties and properties.status then
			tags[name] = true
			count = count + 1
		end
	end
	return tags, count
end

-----------------------------------------------------------------------
-- utilities.statusWithoutSchema()
--
-- Pages with a `status` in their frontmatter and no tag whose schema
-- defines `status` (utilities.statusTags): nothing checks the value,
-- so no query can rely on it. In a space where no tag defines
-- `status`, the field is free everywhere and the check is not shown.
--
-- Returns:
--   Rows { page, status, tags }, or nil when no tag defines `status`.
-----------------------------------------------------------------------
function utilities.statusWithoutSchema()
	local defining, count = utilities.statusTags()
	if count == 0 then return nil end
	local rows = {}
	for _, p in ipairs(query[[from p = index.pages() where p.status ~= nil order by p.name]]) do
		if not utilities.excluded(p.name) then
			local defined, tags = false, {}
			for _, t in ipairs(p.tags or {}) do
				if defining[t] then defined = true end
				table.insert(tags, "#" .. t)
			end
			if not defined then
				table.insert(rows, { utilities.link(p.name), utilities.code(p.status), utilities.code(table.concat(tags, " ")) })
			end
		end
	end
	return rows
end

-----------------------------------------------------------------------
-- utilities.capitalisedStatus()
--
-- Pages with a `Status` key in their frontmatter. YAML keys are
-- case-sensitive, so this is a different field from `status`: no
-- schema checks it and every query on `status` misses the page.
--
-- Returns:
--   Rows { page, Status }.
-----------------------------------------------------------------------
function utilities.capitalisedStatus()
	local rows = {}
	for _, p in ipairs(query[[from p = index.pages() where p.Status ~= nil order by p.name]]) do
		if not utilities.excluded(p.name) then
			table.insert(rows, { utilities.link(p.name), utilities.code(p.Status) })
		end
	end
	return rows
end

-----------------------------------------------------------------------
-- utilities.decisionsProposed()
--
-- Decision records (pages tagged `dr`) in status `proposed`, waiting
-- for a person to decide.
--
-- Returns:
--   Rows { decision, id, date }.
-----------------------------------------------------------------------
function utilities.decisionsProposed()
	local rows = {}
	for _, p in ipairs(query[[from p = index.tag "dr" where p.tag == "page" order by p.name]]) do
		if not utilities.excluded(p.name) and p.status == "proposed" then
			table.insert(rows, { utilities.link(p.name), utilities.code(p.id), utilities.code(p.date) })
		end
	end
	return rows
end

-----------------------------------------------------------------------
-- utilities.decisionsDue()
--
-- Decision records due for review, by the ITAM library's rule and
-- setting: an active status (ITAM.drActive) and `lastReviewed`
-- missing or older than the configured reviewDays. Without ITAM there
-- is no such rule, and the check is not shown.
--
-- Returns:
--   Rows { decision, id, last reviewed }, or nil without ITAM.
-----------------------------------------------------------------------
function utilities.decisionsDue()
	if not (ITAM and ITAM.config and ITAM.drActive) then return nil end
	local limit = utilities.daysAgo(ITAM.config().dr.reviewDays)
	local rows = {}
	for _, p in ipairs(query[[from p = index.tag "dr" where p.tag == "page" order by p.name]]) do
		if not utilities.excluded(p.name) and ITAM.drActive[p.status] then
			local reviewed = utilities.day(p.lastReviewed)
			if reviewed == nil or reviewed < limit then
				table.insert(rows, { utilities.link(p.name), utilities.code(p.id), utilities.code(p.lastReviewed) })
			end
		end
	end
	return rows
end

-----------------------------------------------------------------------
-- utilities.openKanboardTasks()
--
-- The open tasks of the Kanboard library's cache (those with a kbId),
-- on pages that are not excluded.
-----------------------------------------------------------------------
function utilities.openKanboardTasks()
	local tasks = {}
	for _, t in ipairs(query[[from t = index.tasks() where t.kbId and not t.done order by t.dueRaw]]) do
		if not utilities.excluded(t.page) then table.insert(tasks, t) end
	end
	return tasks
end

-----------------------------------------------------------------------
-- utilities.tasksOverdue()
--
-- Open Kanboard tasks whose due date is before today.
--
-- Returns:
--   Rows { task, due, page }.
-----------------------------------------------------------------------
function utilities.tasksOverdue()
	local today = utilities.today()
	local rows = {}
	for _, t in ipairs(utilities.openKanboardTasks()) do
		local due = tonumber(t.dueRaw) or 0
		if due > 0 and os.date("%Y-%m-%d", due) < today then
			table.insert(rows, { utilities.code(t.name), os.date("%Y-%m-%d", due), utilities.link(t.page) })
		end
	end
	return rows
end

-----------------------------------------------------------------------
-- utilities.tasksWithoutDue()
--
-- Open Kanboard tasks without a due date.
--
-- Returns:
--   Rows { task, column, page }.
-----------------------------------------------------------------------
function utilities.tasksWithoutDue()
	local rows = {}
	for _, t in ipairs(utilities.openKanboardTasks()) do
		if (tonumber(t.dueRaw) or 0) == 0 then
			table.insert(rows, { utilities.code(t.name), utilities.code(t.column), utilities.link(t.page) })
		end
	end
	return rows
end

-----------------------------------------------------------------------
-- utilities.waitingForReview()
--
-- Pages under the configured proposedPrefix (for example the folder
-- where agents write) in status `proposed` for more than proposedDays
-- days, waiting for a person's review. The frontmatter `date` counts;
-- a page without one counts from its last change.
--
-- Returns:
--   Rows { page, since }, or nil when no proposedPrefix is configured.
-----------------------------------------------------------------------
function utilities.waitingForReview()
	local settings = utilities.config()
	local prefix = settings.proposedPrefix
	if type(prefix) ~= "string" or prefix == "" then return nil end
	local limit = utilities.daysAgo(settings.proposedDays)
	local rows = {}
	for _, p in ipairs(query[[from p = index.pages() where p.status == "proposed" order by p.name]]) do
		if string.startsWith(p.name, prefix) and not utilities.excluded(p.name) then
			local since = utilities.day(p.date) or utilities.day(p.lastModified)
			if since and since < limit then
				table.insert(rows, { utilities.link(p.name), since })
			end
		end
	end
	return rows
end

-----------------------------------------------------------------------
-- utilities.proposalRows()
--
-- The open change proposals of the Proposals library (installed with
-- the MCP server): pages tagged `change-proposal` under its proposal
-- folder (config key proposals.proposalPrefix, default "Proposals/")
-- whose `outcome` is open or missing. The proposal column links to
-- the library's review page review:<name>, where the list
-- ${proposals.list()} leads too.
--
-- Returns:
--   Rows { proposal, target }.
-----------------------------------------------------------------------
function utilities.proposalRows()
	local prefix = (config.get("proposals", {}) or {}).proposalPrefix
	if type(prefix) ~= "string" or prefix == "" then prefix = "Proposals/" end
	local rows = {}
	for _, p in ipairs(query[[from p = index.tag "change-proposal" where p.tag == "page" order by p.name]]) do
		if string.startsWith(p.name, prefix) and not utilities.excluded(p.name)
			and (p.outcome == nil or p.outcome == "open") then
			local target = type(p.target) == "string" and string.match(p.target, "^%[%[(.*)%]%]$") or p.target
			local review = "review:" .. p.name
			table.insert(rows, {
				utilities.safeName(review) and "[[" .. review .. "]]" or utilities.code(p.name),
				utilities.link(target)
			})
		end
	end
	return rows
end

-----------------------------------------------------------------------
-- utilities.health()
--
-- The health table: ${utilities.health()}.
--
-- One row per check: its title, linking to its detail, and its count.
-- The MCP rows say "no report" when the report page is missing, and
-- the findings row says when rendering is blocked.
--
-- Returns:
--   A markdown block widget.
-----------------------------------------------------------------------
function utilities.health()
	local report = utilities.mcpReport()
	local mcpLink = utilities.link(utilities.config().mcpPage)
	local rows = {}
	for _, check in ipairs(utilities.checks) do
		if check.report then
			local count = "no report"
			if report then
				count = tostring(report[check.report] or "?")
				if check.report == "findings" and report.blocked then
					count = count .. ", rendering blocked"
				end
			end
			table.insert(rows, { check.title, count, mcpLink })
		else
			local found = check.rows()
			if found then
				table.insert(rows, { check.title, tostring(#found), "[[health:" .. check.detail .. "]]" })
			end
		end
	end
	return widget.markdownBlock(utilities.table({ "Check", "Count", "Detail" }, rows))
end

-----------------------------------------------------------------------
-- utilities.healthPage(detail)
--
-- The markdown of the virtual page health:<detail>: one section per
-- check with that detail, each a table of its rows.
-----------------------------------------------------------------------
function utilities.healthPage(detail)
	local parts = {}
	for _, check in ipairs(utilities.checks) do
		if check.detail == detail then
			local found = check.rows()
			if found then
				table.insert(parts, "## " .. check.title .. " (" .. #found .. ")\n\n" .. utilities.table(check.columns, found))
			end
		end
	end
	if #parts == 0 then
		return "# Health\n\nNo such check: " .. utilities.code(detail) .. "\n"
	end
	return "# Health: " .. detail .. "\n\n" .. table.concat(parts, "\n\n") .. "\n"
end

-----------------------------------------------------------------------
-- Virtual page: the detail of a health check
--
-- Pattern: health:<detail>, e.g. health:aspiring
-----------------------------------------------------------------------
virtualPage.define {
	pattern = "health:(.+)",
	run = function(detail)
		return utilities.healthPage(detail)
	end
}
```
