# SilverBullet Libraries

A collection of my libraries and plugins for [SilverBullet](https://silverbullet.md).

## Available libraries

| Library | Description | Status |
|---------|-------------|--------|
| [Kanboard](src/kanboard/kanboard.md) | Integration between SilverBullet and Kanboard. | 🚧 In development |
| [ImageGallery](src/imagegallery/imagegallery.md) | Paginated thumbnail galleries for the images in your space. | 🚧 In development |

Each library is versioned and released on its own; see `make help`.

## Installation

Install the libraries directly from within SilverBullet using the Library Manager.

Repository index:

```
https://raw.githubusercontent.com/finestream/silverbullet-libraries/main/REPO.md
```
